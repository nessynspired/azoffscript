Add Create from Library modal + edit posted clips

You can now create a clip from scratch by selecting items from
all the libraries, and edit posted/live clips with library items.

NEW: CreateFromLibraryModal component
  (src/components/CreateFromLibraryModal.tsx)
  A modal that lets you build a clip from scratch using library
  items. 8 tabs:
    🎬 Format — pick a Ready Bank template (optional)
    🪝 Hooks — multi-select from the Hook Library
    💡 Prompts — multi-select from Prompt Intelligence
    📝 Captions — multi-select from Caption Frameworks
    🔀 Transitions — multi-select from the Transition Library
    📹 Recording — single-select from Recording Style Library
    📋 Recipes — single-select from Shot Recipe Library
    ✏️ Notes — free text production notes
  Plus: title, dates (drop by, cut ready, greenlight, goes live),
  caption, and crew assignment.
  Shows a summary of all attached items at the top.
  Creates the clip with status "Planned" and saves all library
  selections to production_notes.

POSTED/LIVE CLIPS NOW EDITABLE:
  The Watch tab (posted clips) already opened the ClipDetailModal
  on click. That modal already has the "📚 Edit with Libraries"
  button (added in previous commit) that opens the ClipEditor.
  Added a more visible "📚 Edit details & library items" button
  on each Watch tab card to make this more discoverable.
  This means you can edit posted clips — change the title, dates,
  caption, and attach/update library items (hooks, prompts,
  captions, transitions, recording styles, shot recipes, notes).
