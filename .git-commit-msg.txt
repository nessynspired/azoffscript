Separate raw footage from content pipeline — new Raw Footage tab

The crew was dropping raw videos for Vanessa to stitch, but they were
mixing into the content planning pipeline (What's Moving, Studio Flow,
Watch, etc). Now there's a clear separation:

DROP PAGE:
- When dropping a video, women choose: "Content Clip" (for the production
  pipeline) or "Raw Footage" (for Vanessa to stitch). Default is Content.
- Stored in new drop_purpose column on clips table.

RUN SHEET:
- What's Moving = only content clips (no raw footage)
- Recent Drops = only content clips (no raw footage)
- Studio Flow = only content clips (no raw footage)
- Watch = only Live (finished/posted) videos — reverted to original
- NEW "Raw Footage" tab = shows all raw footage drops, visible to ALL crew.
  Women can see each other's raw drops with video playback.
- In the Pipeline (planner) = only content clips (no raw footage)

REQUIRES DATABASE MIGRATION:
  Run supabase/add-drop-purpose.sql in the Supabase SQL Editor.
  Until then, all clips default to "content" so nothing breaks.
