Add Clip Editor — edit scheduled clips and attach library items

You can now click any clip on the calendar (both the Ready Bank
Calendar Builder and the Run Sheet calendar) to open the Clip Editor
and attach library items to it.

NEW: production_notes JSONB column on clips table
  SQL migration: supabase/add-production-notes.sql
  Stores selected library items as JSON:
    { hooks: [], prompts: [], captions: [], transitions: [],
      recordingStyle: null, shotRecipe: null, notes: "" }
  Run this migration in Supabase before using the editor.

NEW: ClipEditor component (src/components/ClipEditor.tsx)
  A modal that opens when you click a clip on the calendar.
  Two sections:
    1. Clip Details — edit title, dates (drop by, cut ready,
       greenlight, goes live), and caption
    2. Library Items — 7 tabs to attach items from the libraries:
       🪝 Hooks — multi-select from the Hook Library
       💡 Prompts — multi-select from Prompt Intelligence
       📝 Captions — multi-select from Caption Frameworks
       🎬 Transitions — multi-select from the Transition Library
       📹 Recording — single-select from Recording Style Library
       📋 Recipes — single-select from Shot Recipe Library
       ✏️ Notes — free text production notes
  Shows a summary of all attached items at the top.
  Search within each library tab.
  Save button writes to the clips table (title, dates, caption,
  production_notes).

This means you can now:
  - Schedule a template from the Ready Bank onto the calendar
  - Click it to open the editor
  - Attach hooks, prompts, captions, transitions, recording styles,
