Add invisible anti-spam to public Join form

Three layers of bot protection that don't add friction for real humans:

1. Honeypot field — a visually hidden "Company website" input that bots
   auto-fill but humans never see. If filled, server returns fake success.

2. Time trap — form tracks when it loaded. If submitted in under 3
   seconds, it's a bot auto-submitting. Server also validates the
   timestamp independently.

3. IP rate limiting — max 3 submissions per hour per IP, checked
   server-side against recent join_submissions rows.

Also adds a basic name-sanity check (must contain a letter) to reject
pure-punctuation or pure-number spam names.

All three return fake success to bots so they don't retry with
different payloads. Real users never see any of this.
