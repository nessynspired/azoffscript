Fix agreements page mobile/PWA overflow — words and buttons off screen

The agreements page was not mobile-friendly on the PWA. Long legal
text, URLs, email addresses, IP addresses, button labels, and
signature IDs were overflowing off the right edge of the screen
instead of wrapping.

Fixed in 5 areas:

1. AGREEMENT PROSE CSS (globals.css)
   - Added overflow-wrap: break-word, word-break: break-word, and
     hyphens: auto to .agreement-prose and all its child elements
   - Added max-width: 100% to prevent any element from exceeding
     the container width
   - Changed code blocks to white-space: pre-wrap so long IDs/URLs
     wrap instead of overflowing
   - Reduced list padding from 22px to 18px so list text doesn't
     push off screen on narrow viewports

2. TOC SIDEBAR + CONTENT LAYOUT (agreements page)
   - Changed from flex-row to flex-col on mobile, flex-row on lg+
   - TOC sidebar is now full-width on mobile (w-full) instead of
     a fixed 256px column
   - Content area gets min-w-0 to prevent flex overflow
   - Content max-height increased from 55vh to 60vh on mobile

3. POPUPS (IntroPopup, AgreementPopup, MainAgreementPopup)
   - Removed mx-2 (was not enough margin on narrow screens)
   - Added overflow-x-hidden to all popup containers
   - Reduced outer padding from p-4 to p-3 on mobile (p-4 on sm+)
   - Increased max-height from 90vh to 92vh for more content space

4. DISCLOSURE SECTIONS (whoami — email, IP, device)
   - Added break-words to email and device text
   - Added break-all to IP addresses (IPv6 can be very long)
   - Applied to both the MainAgreementPopup and AgreementPopup
     versions of the disclosure section

5. BUTTONS AND FORM FIELDS
   - .btn CSS: added max-width: 100% and overflow-wrap: break-word
   - .btn CSS: on screens under 480px, white-space: normal (allows
     long button text to wrap) and reduced padding
   - Date inputs: changed from !w-auto to w-full sm:w-auto so they
     fill the column on mobile
   - Text inputs: added w-full to ensure they don't overflow
   - Signature ID: added break-all
   - Email chip in signature list: added break-all
   - "Waiting on" member names: added break-words
