Fix cropped/cut-off video embeds — TikTok/Instagram no longer clipped

Two fixes for videos being half-covered or cropped:

1. Watch tab (Run Sheet) — social embeds (TikTok, Instagram) were
   forced into aspect-[9/16] overflow-hidden containers, which
   clipped the embed iframe. The TikTok player is ~700px tall
   (header + video + buttons), so a 9:16 box cut it in half.
   Removed the aspect ratio constraint — embeds now size naturally
   and the full video is visible.

2. SocialEmbed compact mode — the portrait wrapper height was
   320px, but a 0.5x scaled TikTok embed is ~350px tall, so the
   bottom was getting cut off. Increased to 360px so the full
   scaled video shows in compact previews (Recent Drops, lobby,
   my-kit, notifications).
