Fix agreement sign API — query members by user_id not id

The sign, whoami, and email APIs were querying members.eq("id", user.id)
but members.id is the member's own UUID, not the auth user ID. The correct
column is user_id which links to auth.users.id. This caused "Member record
not found" for every crew member trying to sign the Creator Release.
